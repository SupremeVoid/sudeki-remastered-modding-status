Sudeki Remastered: modding status

Last updated 2026-10-29

What mods can change in Sudeki Remastered today, what is experimental and what is still planned. Mods go into the mods folder (or the configuration tool's Mods tab) and never touch the installed game. We update this page as the work moves on.

Changelog (latest 2026-10-29)

2026-10-29

  • A balancing editor in the Modding Suite: supported (the Balancing tab).
  • New: balancing values the game's scripts set (.balance files), supported.
  • New: enemies of one zone changed alone (region copies), supported.
  • Data values (.patch) now include character templates (enemy HP, XP, skills).
  • Difficulty scaling: supported with limits (a setting in the ini file for now).
  • Mods tab: balancing mods are compared value by value.
  • New: the Steam and GOG versions of the game, supported.
  • mod.ini: one name and a Markdown description in the author's language.
  • New: the remaster's own content (benches, sitting down), which mods can replace.
  • Interfaces (menus, the HUD): not planned; interface models are no longer listed as coming.
  • The Modding Suite and the Animation Editor save into a target mod chosen in their toolbar.

2026-10-28

  • Initial status.

Mods in general

Mod folders and .zip files, mod.ini (name, author, version, a Markdown description)SupportedOne name and description in the author's language; a mod works the same in every language of the game.
Steam and GOG versions of the gameSupportedThe same mods on both.
Load order, conflicts between mods, switching mods on and offSupportedIn the configuration tool's Mods tab. Balancing mods are compared value by value: the Mods tab lists every value two mods set differently and which one wins.
TexMod / uMod packages (.tpf) turned into modsSupportedAll 406 known texture hashes matched.
Checking a mod (errors and warnings for every file)SupportedModding Suite, Mods tab.
Changes while the game runsSupportedPictures, .materials and .lights are taken again when saved ([Mods] HotReload). Everything else applies at start.
Requires= (a mod that needs another one)Supported, with limitsChecked and warned about; the game does not act on it yet.

Textures and models

Replacing any file of the game's archives (models, textures, entities, tables)SupportedSame format as the original.
High-resolution textures (.png, .jpg, .dds BC1-BC3, BC7)SupportedAny resolution; animated textures frame by frame.
New textures under new namesSupportedFor a mod's model that names them.
Surface relief and parallax per texture (.materials)Supported
Models exported to glTFSupportedAll 2,432 models of the game.
Models imported from glTF (props, effects, outfits)Supported, with limitsCharacters keep their skeleton (same bones). Not yet: tangent frames, two-component UVs, cutscene morphs. Interface models are not planned (see Interfaces).
Showing the name of the texture under the cursor in the gamePlanned

Sound and video

Movies (Bink 1 .bik)Supported
Whole sound banks (.xwb, .xsb, .sf)Supported
Single sounds (.wav)SupportedReplaces one entry of a wave bank.
New sounds and cues, retimed speechExperimentalLooping new cues and the lip sync of retimed speech are not tested yet.

Texts, data and balancing

Texts (.strings), in every languageSupportedSeveral mods add up.
Data values (.patch)Supported, with limitsSeveral mods add up, character templates (enemy HP, XP, skills) included. The party's base stats and ability gains are kept in the save, so a change shows in a new game only.
A balancing editor in the Modding SuiteSupportedThe Balancing tab: 14 tables (weapons, armour, potions, the party, abilities, the level curve, skills, enemies, drops ...) with the game's names; single cells or a whole column at once (multiply, add, set).
Balancing values the game's scripts set (.balance)SupportedRune strengths, blacksmith and shop prices, what shops sell, traders' prices, defence factors, the AI's damage factor, quest rewards. Quest rewards are not tested in the game yet.
Enemies of one zone changed alone (region copies)SupportedA copy of a monster for one zone, edited on its own; bosses are left out (the scripts spawn them).
Difficulty scaling (damage, enemy HP, XP, money)Supported, with limitsOn top of whatever balancing mods set. A setting in the ini file for now, not yet in the menus.
Interfaces (menus, the HUD)Not plannedThe layouts live in the interface models and the game's program, out of a mod's reach. Interface changes come as features of the remaster itself, such as its options menu.

Animation

Poses and animations for photo mode (.anim)SupportedMade with the Animation Editor.
Replacing the game's own animation clips (walks, idles, attacks)SupportedOn any skeleton: party, NPCs, monsters.
Clip events (footsteps, sounds, effects)Supported
New clips played by a character's statesSupportedThrough a .patch of the character's .ani file.

Light and look

New lights in zones, changes to the game's lamps, torches and fires (.lights)SupportedPlaced in the Modding Suite's zone view; ray-traced shadows where ray tracing is on.
Colour grading (LUTs) from modsPlanned

World and content

New doors, rooms and places to sit (.doors, .rooms, .places)ExperimentalA new door into a tavern and places to sit work in the game. A copied room loads but its geometry is not drawn yet.
The remaster's own content (the benches of New Brightwater, sitting down)SupportedBuilt in and always there; a mod replaces any piece of it with a file or place of the same name.
New characters (NPCs with an outfit, a name, lines, a walk)ExperimentalMade in the Modding Suite. Voices for new lines are not supported yet.
Script mods (quests, events, mechanics)In progressA disassembler, an assembler and a linker exist; a decompiler and a compiler are next.
Whole new levelsNot plannedNeeds collision and navigation formats that are not decoded.
Save games, the game's codeNot plannedMods change the game's data, not its program or your saves.

Tools for modders

Configuration tool, Mods tabInstall, order, switch and import mods; the modding guide in five languages.
Sudeki Modding SuiteEvery asset of the game read from your own install: textures, models, characters, animations, zones, sounds, texts, data. Checks mods and makes them (materials, lights, balancing, new characters, glTF import) into the target mod chosen in its toolbar.
Sudeki Animation EditorPoses and animations for Tal, Ailish, Buki and Elco, and edits of the game's own clips for any skeleton, saved into the target mod chosen in its toolbar.
Extract Game AssetsThe game's models (glTF) and textures (PNG) from your own install, as a start for mods.
Sudeki Remastered is a fan project; you need your own copy of Sudeki. Source of this page: github.com/SupremeVoid/sudeki-remastered-modding-status
